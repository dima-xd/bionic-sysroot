# Bionic sysroot (armeabi-v7a)

Unmodified 32-bit Android 7.0 (API 24) bionic binaries, ready to be consumed by
a container or emulator that runs ARMv7 Android applications on a 64-bit host
without a 32-bit ABI of its own.

Everything here comes from the official emulator system image
`system-images;android-24;default;armeabi-v7a`, package
`armeabi-v7a-24_r07.zip` (SHA-1 `3454546b4eed2d6c3dd06d47757d6da9f4176033`).
Nothing is patched: the whole point is that the guest sees exactly the ABI a
real ARMv7 Android 7 device exposes, so games and their third-party libraries
behave the way their authors tested them.

Provenance: `system.img` (ext4) from the image above, read with `debugfs`.
Files were copied byte for byte from `/system/bin/linker` and `/system/lib/*.so`.

regenerated by `tools/fetch-sysroot.ps1`.

## Why these files

* `linker` relocates itself and everything else, and owns the namespace and
  `dlopen`/`dlsym` semantics. A container boots it the way the kernel does: a
  mapped `ET_DYN` image plus an initial stack holding `argc/argv/envp/auxv`,
  then `_start` with the stack pointer in `r0`.
* `libc.so` brings TLS, errno, stdio, pthreads, the dynamic loader glue and the
  ARM EABI helpers, so the container does not have to emulate any of it.
* `libm.so`, `libdl.so`, `libstdc++.so` and `libz.so` are the libraries that the
  linker and the C++ runtime expect to find by name.

## Usage

Consumers embed these binaries into their own runtime at build time (for
example by turning each file into a byte array and copying it into guest memory
on first launch), so nothing has to be shipped as an external file. Keep the
directory layout as is: `bin/linker` plus `lib/*.so`.

## Regenerating

`tools/fetch-sysroot.ps1` installs the pinned system image through the Android
SDK manager, verifies the archive SHA-1, extracts `system.img` and pulls these
files out of it with `debugfs` (WSL with e2fsprogs is required). It rewrites
`armeabi-v7a` and `CHECKSUMS.txt`; commit the result if any hash changed.

```powershell
pwsh tools/fetch-sysroot.ps1
```
